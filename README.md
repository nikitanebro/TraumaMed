# Медик КПК

Наручное приложение медика: раненые, таймеры жгутов, аппаратные кнопки, подтверждения вибрацией. Работает полностью офлайн.

## Что умеет v0.1

- Список раненых крупными карточками под перчатки, тёмная тема.
- Жгуты на каждого раненого: конечность, время наложения, живой таймер. Цвет меняется на порогах предупреждения и критическом.
- Таймеры живут в фоновом сервисе: экран можно гасить, вибрация на порогах придёт всё равно.
- Аппаратные кнопки, срабатывают по удержанию примерно 0,6 с:
  - громкость вверх — жгут на выбранного раненого (если никого нет, создаётся новый); конечность уточняется потом тапом по «?»;
  - громкость вниз — новый раненый.
  - Любую кнопку можно переназначить в настройках, там же видно код последней нажатой кнопки (для кнопок XCover).
- Вибрация: одна короткая — принято; три средних — порог предупреждения; четыре длинных — критический порог.
- Ночной режим с минимальной яркостью, экран не гаснет, пока приложение открыто.
- Данные сохраняются на телефоне и переживают перезапуск.

Пороги по умолчанию 60 и 120 минут. Выставь их в настройках по своему протоколу.

## Как поставить

Каждый пуш в `main` собирает APK через GitHub Actions и выкладывает его в Releases. Самая свежая сборка всегда лежит в Releases → Latest → `medic-kpk.apk`. На телефоне разреши установку из неизвестных источников для браузера.

APK подписан постоянным отладочным ключом из `keystore/`, поэтому новые версии ставятся поверх старых без потери данных.

## Как собрать самому

Android Studio → Open → папка проекта → Run. Или из консоли: `./gradlew :app:assembleDebug`.
