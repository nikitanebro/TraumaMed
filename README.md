# TraumaMed — Медик КПК

Наручное приложение медика для защищённого телефона (Samsung XCover7 Pro и подобных). Работает полностью офлайн, экран горизонтальный.

## Что умеет v0.2

**Раненые и жгуты**
- Раненые — жёлтым, жгуты — красным. Карточки крупные, под перчатки; на широком экране в два столбца.
- Жгут: конечность на схеме тела, время наложения, живой таймер. На пороге предупреждения строка заливается тёмно-красным, на критическом — красным целиком.
- Таймеры живут в фоновом сервисе: экран можно гасить, вибрация на порогах придёт всё равно.

**Ранения**
- Виды: пулевое, осколочное, МВТ, ожог, перелом, ампутация, ЧМТ/контузия, другое.
- Зона: голова, шея, грудь, живот, таз, спина, конечности. Выбор на схеме тела.
- Схема — раненый лицом к тебе: его правая сторона слева.
- Тап по записи ранения — убрать её.

**Журнал помощи**
- Кнопка «Помощь» справа или на карточке. Двенадцать быстрых манипуляций: давящая повязка, тампонада, гемостатик, окклюзионная повязка, декомпрессия, НПВ, коникотомия, обезболивание, транексам, инфузия, иммобилизация, согревание.
- Тап по манипуляции — запись с текущим временем, окно не закрывается, можно отметить несколько подряд.
- В поле сверху — подробности (препарат, доза, место) или своя заметка текстом. Текст добавляется к следующей отмеченной манипуляции или сохраняется отдельной записью.
- Записи видны на карточке по времени; тап по записи — убрать её.

**Карта и СК-42**
- Офлайн-карты из файлов `.mbtiles` и `.sqlitedb` (RMaps/Locus). Например, Генштаб из SAS.Planet: экспорт в MBTiles или «RMaps SQLite».
- «Карты» → «Загрузить карту из файла»: файл копируется в память приложения, дальше открывается без интернета.
- Координаты центра карты в СК-42 (X, Y Гаусса–Крюгера с номером зоны) и WGS-84.
- Километровая сетка СК-42 поверх любой карты, шаг подбирается по масштабу. Подписи — две последние цифры километра, как на топокарте.
- Свой GPS (без сервисов Google), раненые на карте жёлтыми метками с номером, красная точка — есть активный жгут.
- Новый раненый получает координаты из GPS. Если он не там, где ты: выбери его, наведи перекрестие и нажми «№N сюда».
- Пересчёт WGS-84 → СК-42 по ГОСТ 32453-2017, сверен с PROJ до миллиметра.

**Кнопки**
- Удержание ~0,6 с: громкость вверх — жгут на выбранного (если никого нет — новый раненый); громкость вниз — новый раненый.
- Любую кнопку можно переназначить в настройках, там же виден код последней нажатой (для кнопок XCover).
- Вибрация: одна короткая — принято; три средних — порог предупреждения; четыре длинных — критический.

Пороги жгута по умолчанию 60 и 120 минут — выставь в настройках по своему протоколу.

## Как подготовить карту

Карту готовишь на компьютере, а в телефон переносишь одним файлом.

1. В SAS.Planet выбери слой карты и выдели нужную область инструментом выделения.
2. В окне операций с выделенной областью сначала загрузи тайлы для нужных масштабов (вкладка загрузки).
3. На вкладке экспорта выбери формат **MBTiles** или **RMaps SQLite** и отметь те же масштабы.
4. Скопируй файл на телефон и открой в приложении: «Карта» → «Карты» → «Загрузить карту из файла».

Названия вкладок в разных версиях SAS.Planet немного отличаются.

Каждый следующий масштаб увеличивает файл примерно вчетверо. Для пешей работы обычно хватает масштабов с 10 по 15. Брать больше 16 без нужды не стоит: файл разрастается до гигабайтов.

Проверка привязки: встань в точку, которую знаешь по бумажной карте, нажми «Моё место» и сравни X/Y. Расхождение в пределах точности GPS (5–15 м) нормально. Если ошибка большая, значит, карта не в проекции Web Mercator. Например, слои Яндекса в другой проекции и лягут со сдвигом, их не бери.

## Как поставить

Каждый пуш в `main` собирает APK через GitHub Actions и выкладывает в Releases. Свежая сборка: Releases → Latest → `medic-kpk.apk`.
APK подписан постоянным ключом из `keystore/`, обновления ставятся поверх без потери данных.
